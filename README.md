# Shubham Aggarwal

Personal landing page, served at [shubham-aggarwal.tech](https://shubham-aggarwal.tech).

Static HTML with no build step. `index.html` is the whole site; styles are inline.
GitHub Pages serves it from the default branch, and the `CNAME` file sets the custom
domain, which also makes GitHub 301-redirect the old `*.github.io` URL here.
